# 소방시설 법규 검토 PWA (무료 운영 중심 MVP)

## 포함 파일
- `index.html`: 건축물 입력, 검토 체크리스트, 법령 링크, 이력/JSON 내보내기
- `manifest.webmanifest`: 홈 화면 설치를 위한 앱 설정
- `sw.js`: 앱 파일 캐시(설치 후 기본 화면을 오프라인에서 열기 위한 기능)
- `icon.svg`: 앱 아이콘

## 중요한 제한
- 현재 버전은 현장 검토 보조용 프로토타입이며 법적 설치 대상 여부를 확정하지 않습니다.
- 법령 API 자동 조회/개정 감지, OCR 자동 추출, 사용자 로그인 및 기기 간 동기화는 아직 구현되어 있지 않습니다.
- 건축물 자료는 브라우저의 로컬 저장소에 저장됩니다. 브라우저 데이터 삭제/기기 분실 시 사라질 수 있으므로 `JSON 내보내기`로 백업하세요.
- 첨부파일은 현재 화면에서 파일명/메타데이터를 표시할 뿐, 파일 본문을 저장하거나 OCR로 읽지 않습니다.
- PWA 서비스워커 설치에는 HTTPS 주소가 필요합니다(또는 개발용 localhost).

## 무료로 아이폰에 설치하는 방법
1. GitHub 계정에서 새 공개 저장소(repository)를 만듭니다.
2. 이 폴더의 네 파일을 저장소 최상위에 업로드합니다.
3. 저장소의 Settings → Pages에서 배포 소스를 `Deploy from a branch`, 브랜치 `main`, 폴더 `/(root)`로 지정하고 저장합니다.
4. 배포된 `https://...github.io/.../` 주소를 아이폰 Safari로 엽니다.
5. 공유 버튼 → `홈 화면에 추가` → 추가를 누릅니다.
6. 앱을 한 번 온라인으로 열어 캐시를 준비하면 기본 화면은 오프라인에서도 열릴 수 있습니다. 외부 법령 링크를 조회하려면 인터넷이 필요합니다.

## 안드로이드
배포된 HTTPS 주소를 Chrome에서 열고 메뉴에서 `앱 설치` 또는 `홈 화면에 추가`를 선택합니다.

## PC
배포된 주소를 Chrome/Edge에서 열어 사용할 수 있습니다. 로컬 파일을 더블클릭하는 방식으로는 PWA 설치/서비스워커가 동작하지 않을 수 있습니다.

## 개인정보 주의
공개 GitHub Pages는 앱 코드와 정적 파일을 공개 배포합니다. 입력한 건축물 정보는 브라우저 안에만 저장되도록 설계했지만, 실제 민감한 현장 정보를 입력하기 전에는 본인 기기 보안과 백업 정책을 확인하세요. 공개 저장소에 건축물대장 파일이나 실제 업무 데이터를 업로드하지 마세요.
